# Mova Visual

Portfólio de **Rob / Mova Visual**, dedicado a vídeo, design e narrativa visual.

O site apresenta uma seleção de projetos para dança, eventos e marcas, reunindo filmagem, edição e design em uma navegação visual, responsiva e simples de explorar.

## Projetos em destaque

- Rio Dance Lab
- Intensivo Thami Nunes
- Templum Fitness
- Núcleo 7.0
- Outros trabalhos

Cada projeto possui uma área de prévia e um link para a respectiva pasta de materiais no Google Drive.
